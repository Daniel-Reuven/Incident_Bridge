Settings

Kept encrypted in the database and used from the next start. backend/.env only gave their first values at setup - changing it now has no effect. An empty field uses the default.

HTTPS

Take effect when the server starts. HTTP from this computer itself always stays open, so a wrong setting cannot lock you out.

Certificate

AI analysis

Applied at once. The API key is stored encrypted and never shown again; left empty, the key in backend/.env is used (and not saved).

Import data

JSONL files - one JSON record per line, like the samples in data/. Records whose id is already stored are skipped, never overwritten; invalid ones are skipped and listed. Import the sites before the mailing lists (lists refer to sites).
